Instalasi Git Remote GitHub

Instalasi Git

winget install --id Git.Git -e --source winget

Via Windows Package Manager

Instalasi Git terbaru melalui Windows Package Manager (cepat dan resmi).

git --version

Verifikasi Versi

Cek apakah Git sudah terinstall dengan benar.

git config --global user.name "Nama Anda"
git config --global user.email "email@anda.com"

Konfigurasi Awal

Setel nama dan email global untuk commit Git.

Remote Project ke GitHub

git init

Inisialisasi Repo

Membuat repository Git lokal baru.

git add .

Add Files

Menyiapkan semua file untuk commit.

git commit -m "project"

Commit Perubahan

Simpan perubahan dengan pesan "project".

git branch -M main
git remote add origin "nama repo github"
git push -u origin main
