Instalasi Git Remote GitHub

Instalasi Git di VSCode

Tutorial lengkap menginstall Git dan konfigurasi awal

winget install --id Git.Git -e --source winget

Instal via Windows Package Manager

Perintah tercepat untuk menginstall Git terbaru di sistem Windows menggunakan Windows Package Manager.

git --version

Verifikasi Instalasi

Mencek versii Git yang berhasil terinstall di sistem.

git config --global user.name "Nama Anda"
git config --global user.email "email@anda.com"

Konfigurasi Global

Menetapkan nama pengguna dan email untuk commit Git (wajib dilakukan sekali).

Remote Project ke GitHub

Tutorial meremotte project lokal ke repository GitHub

git init

Inisialisasi Repository

Membuat repository Git lokal baru di folder project Anda.

git add .

Menambah File

Menyiapkan semua file di working directory untuk commit.

git commit -m "project"

Commit Perubahan

Menyimpan perubahan dengan pesan commit "project".

git branch -M main
git remote add origin "nama repo github"
git push -u origin main

Git Flow Lengkap

Setelah commit, arahkan project ke remote repository GitHub dan push ke branch main.
